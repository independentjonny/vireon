# Roadmap

## Version 1: Operating Manual and Rename

- Establish Vireon product constitution.
- Rename product surfaces to Vireon.
- Introduce My AI CFO as the user-facing assistant concept.

## Version 2: Vault-First Foundations

- Add typed Vault evidence contracts.
- Connect recommendations to source records.
- Add Vault completeness and missing-data actions.

## Version 3: AI Decision Engine 2.0

- Add expected financial value and opportunity scoring.
- Sort actions by value.
- Expand explanations, evidence, assumptions, risks, alternatives, and next actions.

## Version 4: My AI CFO Workspace

- Replace deterministic placeholder answers with Vault-grounded context retrieval.
- Add pinned CFO panel.
- Add confidence and missing-data handling.

## Version 5: Financial Timeline

- Build cross-domain event stream.
- Connect documents, transactions, goals, rates, property, loans, milestones, and decisions.

## Version 6: Digital Financial Twin

- Add baseline financial model.
- Add first scenario simulations.
- Recalculate cash flow, borrowing, tax, net worth, retirement, and goals.

## Version 7: Automations and Proactive AI

- Add daily briefing.
- Add one-click workflows.
- Add alerts for rates, subscriptions, cash, salary, credit cards, documents, and affordability changes.

## Version 8: Money Map and Life Planner

- Add interactive financial flow map.
- Add life-planning assumptions and continuous plan adjustment.

## Version 9: Professional Mode

- Add audit trail, evidence packs, assumptions, document citations, and adviser/broker/accountant workflows.

## Version 10: Full AI Financial Operating System

- Complete Vault onboarding.
- Live balance sheet.
- Financial health score.
- Ranked action plan.
- 30-year wealth projection.
- AI CFO.
- Digital twin.
- Proactive intelligence.
